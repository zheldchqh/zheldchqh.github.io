    👋 블로그 소개 #

    이 블로그는 제가 공부하면서 정리한 수학과 과학 지식을
    더 많은 사람들과 쉽고 직관적으로 공유하기 위해 만들었습니다.

    복잡하게 느껴지는 개념도, 누구나 이해할 수 있도록
    예제 중심의 설명과 시각화를 활용해 소개합니다.

    🎯 목표 #

    • 수학과 과학의 개념을 쉽고 명확하게 전달
    • 학습 과정에서 마주친 직접적인 질문과 풀이 공유
    • 누구나 함께 배우고 성장할 수 있는 열린 공간 만들기

    🙋‍♂️ 운영자 소개 #

    • 이름: OOO
    • 관심 분야: 순수수학, 이산수학, 고전역학, 과학철학
    • 사용하는 도구: LaTeX, Python (SymPy, NumPy), Markdown
    • 공부하면서 느낀 걸 글로 쓰는 걸 좋아합니다
